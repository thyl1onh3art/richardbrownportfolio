Project Overview

I designed and configured this network to simulate the equipment and connectivity found in a small office. A Cisco 2960 switch connects the wired endpoints, while the wireless router provides the default gateway and wireless access for mobile devices.

The devices are configured within the 192.168.8.0/24 subnet. The lab includes user workstations, a laptop, smartphone, shared printer and web server.

Project Objectives

  • Design a clear and functional Local Area Network.
  • Assign and document IPv4 addresses.
  • Connect wired and wireless client devices.
  • Include common office services and equipment.
  • Test communication and identify connectivity problems.

What I Learned

This project strengthened my understanding of how devices communicate within a LAN and how switches, routers, IP addresses, subnet masks and default gateways work together.

It also gave me practical experience in planning a network before deployment, documenting device information and using Cisco Packet Tracer to investigate configuration and connectivity issues.
